## HTTP 500 и границы вывода

Последний ранее разрешённый реальный запрос завершился HTTP 500. В текущем проходе новых отправок не было. Закрытые runtime logs недоступны, поэтому конкретная upstream-причина 500 **не установлена**. Нельзя считать доказанными отсутствие SMTP, ограничение получателя, квоту или неверный ключ.

Отдельно доказана проблема развёртывания: локальный исправленный код не находится на production. Для его публикации необходим деплой именно существующего целевого проекта, а не создание нового проекта. Альтернативный Git-деплой технически доступен через авторизованный GitHub CLI, но к репозиторию подключены два production-проекта; поэтому такой вариант вынесен на отдельное подтверждение до публикации. Деплой не даёт гарантии исправления внешней SMTP-конфигурации.

Состояния нужно проверять раздельно: доступность API подтверждена; принятие реального запроса Supabase, доставка письма, открытие письма на Android и успешная облачная авторизация не подтверждены.
