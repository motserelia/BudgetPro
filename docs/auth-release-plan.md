## Проверенная конфигурация

Vercel CLI авторизован. Все три переменные `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `BUDGETPRO_AUTH_REDIRECT_URL` присутствуют и включены для production. Их тип Sensitive: значения недоступны для чтения. Это не означает, что значения пустые или неверные; содержимое и корректность проверить нельзя.

Получены записи пяти production HTTP 500 запросов; безопасного upstream-кода из доступных данных получить не удалось. Дополнительный запрос с заведомо фиктивным refresh token также вернул HTTP 500 `refresh_failed`; реальный пользовательский токен не использовался и письмо не отправлялось. Точная причина сбоя пока не доказана.

API-патч исправляет REST-параметры OTP и redirect по умолчанию, различает ошибки и добавляет безопасные записи стадий/кодов ошибок без email, ключей, URL с токенами или полного upstream body. После согласованной публикации эти записи можно будет прочитать самостоятельно.

Без доступа к Supabase нельзя проверить SMTP host/port/sender и его доставку, квоты, разрешённых получателей, Site URL, Redirect URLs и почтовые шаблоны. Изменять эти настройки в данном деплое не предлагается.
