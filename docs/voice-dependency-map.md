# Voice replacement dependency map

Checkpoint: 5217efe; previous package/Android version: 1.2.0.

- Electron main → IPC/preload → desktop/voice/whisper-engine.js → whisper-server/CLI and downloaded ggml models. scripts/prepare-whisper.js and build.extraResources existed only for this engine.
- www/index.js → voice-controller/core/capture → desktop bridge, with separate browser SpeechRecognition and Android BudgetPROVoice fallback handlers.
- Android MainActivity.VoiceBridge → SpeechRecognizer/RecognizerIntent → renderer callbacks. NotificationsBridge, reminders and TraceBridge are independent and retained.
- Root index.js contained another browser/native implementation (Vercel static entry). Both entry points must use the same new modules.
- Existing number normalizer depended on old core language helpers. Replaced with standalone parser.
- Old voice tests/benchmark exercise removed engines and must be replaced.
- Floating button, drag shield/trash, position persistence, theme CSS and financial draft parser do not require the old engines; retained.
- Service workers cache application assets; replace module list and bump cache; voice API bypasses caching.
- Android assets/public are generated by Capacitor (not tracked); regenerate after replacement.

No transaction storage, authentication storage, categories, backups or user data are deleted.
